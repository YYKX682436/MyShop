The Display P3 and Rec. 709 profiles in this directory come from
[Compact ICC Profiles](https://github.com/saucecontrol/Compact-ICC-Profiles)
by saucecontrol, released under CC0 1.0. They let the image
processor supply an input ICC profile for an unambiguous SDR HEIF/AVIF nclx
declaration that the Ubuntu Noble libvips loader cannot otherwise retain.
