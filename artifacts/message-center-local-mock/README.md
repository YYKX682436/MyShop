# Message center UI evidence

These screenshots were captured on 2026-11-26 from the local Next.js production build, with a synthetic API fixture bound to `127.0.0.1`. They contain sample users, orders, notifications, and support messages only; they are not screenshots of the production site and do not use production data.

The set covers customer message entry, notification feed, customer support, notification management, and the admin support workbench. Customer screens include mobile and desktop widths in light and dark themes. Admin screens include mobile and desktop widths in the light theme.

Viewport sizes: mobile `390 × 844` CSS pixels; desktop `1440 × 1000` CSS pixels. The captured images are stored at their rendered viewport dimensions.
