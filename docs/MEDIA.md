# 公开资源

后台资源库读取 `media_assets` 和 `media_references`，由数据库分页；可按名称、时间、展示文件大小、图片/视频、用途及未使用状态筛选。用途来自当前商品、头像、站点图标或公告引用；同一资产可以同时出现在多个用途中，无引用的手动上传归为其他。售后及客服私有附件使用独立目录和权限，不列入公开资源库。

旧公开图片与服务器头像在首次切换时登记并回填当前引用，旧地址保持不变；不会批量重压或删除旧文件，也不会修改订单历史快照。共享图片按原上传内容 hash 复用有效资源并明确反馈；删除后再次上传会得到新的资源和地址。头像属于账户独立生命周期，不与商品或其他账号合并，商品图片选择器不展示账号头像。

## 图片处理和缓存

管理图片上限 10 MiB，头像和站点图标上限 5 MiB。普通输入支持 JPEG、PNG/APNG、GIF、WebP、BMP、AVIF、HEIC 和 HEIF；服务端检查格式签名并以 libvips 实际解码结果为准。图片输入有尺寸、像素、处理时限及并发限制。GIF、APNG 和动画 WebP 保留动画，不压成首帧。

新静态图片无论原文件大小都会尝试处理。展示版优先 WebP，以 300 KiB 为目标并限制质量尝试次数；商品缩略图和头像另有更小尺寸。原图中方向、颜色和透明度按处理器策略保留，长图按宽度适配；识别到的二维码采用无损并检查可读性，无法安全转换时保留合适的输入。质量与保真优先，因此不是所有文件都保证小于目标。资源详情中的原始、展示和清晰版大小分别统计，不能用清晰版大小计算展示版压缩率。

HEIC/AVIF 的 nclx 色彩声明由本地工具检查；支持的广色域配置转换到 sRGB，未声明色彩时按 sRGB 处理并提示，无法可靠处理的 HDR 或冲突声明会返回错误，避免静默改变色彩。ICC 配置随图片转换处理。

展示、缩略和清晰版是独立、不可覆盖的地址，卡片、头像及资源库使用较小版本；主图和正文的查看器打开时才请求清晰版。受管的新地址和符合条件的旧地址使用长期缓存；资源变化生成新地址。外站图片由浏览器直接请求，不通过任意 URL 抓取代理。公开读取检查资产状态、路径和符号链接，已删除资产即使清理失败也不再作为公开文件提供。浏览器和代理已缓存的副本不能强制撤回。

旧根目录图片的卡片及正文缩图仍可由 Next 图片优化器缓存；每次优化器请求在读取缓存前都会向本地 API 检查对应资源仍可公开，已删除或无法确认状态的资源不会因服务器优化缓存而重新提供。已保存到浏览器或第三方缓存的字节无法主动撤回；新图片直接使用预生成尺寸，无需再由优化器重复处理。

API 镜像安装 libvips CLI、HEIC/AVIF 解码组件及 sRGB 色彩配置，使用参数数组运行本地文件处理。生产发布 workflow 会对最终 API 镜像运行真实 HEIC、AVIF 解码探针。图片经临时文件及同一挂载内的硬链接原子发布，公开上传目录须支持硬链接并持久挂载。

## 视频

管理员可上传 MP4、MOV 和 WebM。默认单文件最大 1 GiB（`VIDEO_MAX_UPLOAD_BYTES`），tus 分块默认 8 MiB（`VIDEO_MAX_CHUNK_BYTES`），普通图片和私有附件的请求上限保持独立。上传会话与账号绑定，支持暂停、继续、取消和失败重试；刷新后须重新选择同一文件，浏览器不会自动保留文件读取权限。

未完成的上传会话在七天未继续后过期；过期后需重新上传。后台定期清理过期的私有会话文件，并在资源状态中提示失效。

会话流式存放在持久化的私有上传目录。后台单任务检查真实封装和编码：可兼容的 H.264/AAC MP4 重封装为 faststart MP4，其他受支持的视频转为 H.264/AAC MP4；处理不占用持续等待的 HTTP 请求。中断后可恢复处理或明确重试。资源库提供受控播放器和完整直链；成品公开 GET、HEAD 和 Range，临时上传文件不公开。代理限制和持久化要求见 `DEPLOYMENT-SHARED-SERVER.md`。
