# 图片资源

后台资源管理仅列出公开上传目录根部的旧 UUID 图片和新资源；头像目录和售后私有附件不属于资源库。新图片按处理后的 SHA-256 命名，重复上传会复用同一 URL，资源名称以首次上传的文件名为准，保存在上传目录的 `.media-info/` 中。旧文件不会被迁移或改写，旧 URL 保持可用。

列表中的时间取文件最后修改时间；旧图如果曾被复制或恢复，该时间可能与最初上传时间不同。

上传限制为 10 MB（头像 5 MB），解码前限制单边 12,000 像素、总计 2,000 万像素，进程内同一时间只处理一张图片。JPG 和非动画 PNG 最长边缩至不超过 2,560 像素，JPG 使用 0.85 品质并校正 EXIF 方向，PNG 保留透明度；无缩放和方向修正需求时，重新编码更大则保留原文件。GIF、动画 PNG、WebP 和 BMP 保留原始字节。WebP 仅检查容器和尺寸，不在服务器端解码。不同图片的实际压缩效果取决于内容。

方向检查只读取 EXIF，不解压 PNG 内的压缩文字等元数据；PNG 的 EXIF 数据上限为 1 MB。

新文件通过上传目录中的临时文件与硬链接原子发布，存储文件系统须支持同一目录内的硬链接。共享服务器继续使用现有 `/app/uploads` 挂载，不需要新增服务或数据库表。资源列表由管理员鉴权；公开图片读取拒绝隐藏路径和符号链接。删除头像的独立机制保持不变；资源库不提供删除或自动清理。
